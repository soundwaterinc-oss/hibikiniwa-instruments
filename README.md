# KUKURU — くくる・心の持続音

音楽療法の知見（40Hz聴覚刺激・共鳴呼吸・バイノーラルビート）と、世界53種の民族音階を統合した**パラメトリック・ドローン楽器**。ブラウザだけで動き、依存ライブラリはありません。

> *kukuru*（くくる）は沖縄の言葉で「心」。

A browser drone instrument that layers music-therapy techniques (40 Hz auditory stimulation, 0.1 Hz resonance-breathing guidance, binaural / isochronic beats) on top of 53 world tunings — Ryukyu, ragas in just shruti, Arabic and Turkish maqam, Persian dastgah, gamelan, Ethiopian kignit, harmonic series — plus any Scala `.scl` file. Pure Web Audio, no build step.

## 全体構造

```
┌ 調律 ─────────────┐   ┌ 音色 ───────────┐   ┌ 有機的揺らぎ ─────────────┐
│ 音階（53種＋.scl） │──▶│ 倍音数・減衰     │──▶│ ボイスごとに独立した超低速 │
│ 鳴らす度数を選択   │   │ 奇数/偶数バランス│   │ LFO（共通クロックなし）    │
│ 基音・サブ/上オクターブ│ │ ユニゾン・デチューン│ │ ピッチ・音量・定位が漂う   │
└───────────────────┘   └─────────────────┘   └──────────────────────────┘
                                   │
            ┌ 駆動モード：持続（シュルティ箱）/ タンプーラ撥弦循環 / 両方 ┐
                                   ▼
   フィルター ─▶ 【療法】40Hz等のAM ─▶ 【呼吸】音量と音色の満ち引き ─▶ 残響・ディレイ
                                                                           │
   【療法】アイソクロニック音 / バイノーラル（残響を通さず左右差を保持）──────┤
                                                                           ▼
                                         セッション（フェード・タイマー）─▶ リミッター
```

## 使い方

1. `index.html` を開く（後述のとおりローカルサーバー経由）。
2. 「はじめに・安全のために」を読み、音量を小さめにしてから **鳴らす**。
3. 左の **音階** を選び、**鳴らす度数** をタップで組み合わせる。音階円には、鳴っている度数と、倍音が音階のどこに落ちているか（ピッチクラスに折り畳んだスペクトル）が表示されます。12本の目盛りは12平均律の位置なので、微分音のずれがそのまま見えます。
4. **シーン** から始めると目的別の設定がまとめて入ります。

| 操作 | 内容 |
|---|---|
| スペース | 再生・停止（停止はフェードアウト） |
| スライダーをダブルクリック | 初期値に戻す |
| 設定をコピー / 貼り付けた設定を読込 | 全パラメータをJSONで保存・共有 |
| Scala (.scl) を読み込む | [Scala archive](https://www.huygens-fokker.org/scala/downloads.html) の5,000以上の音階をそのまま使える |
| MIDIをつなぐ | ノート→基音、CC1/74→フィルター、CC7→音量、CC71→倍音減衰、CC91→リバーブ |
| `window.kukuru` | コンソールから `kukuru.set('beatHz', 40)` などで直接操作 |

## パラメータ一覧

すべて `js/params.js` のスキーマで定義され、UIはそこから自動生成されます。項目を足すときはスキーマに1行追加し、`engine.js` の `applyKey` に反映処理を書くだけです。

| グループ | パラメータ |
|---|---|
| 調律 | 基音 30–600Hz（対数）、微調整 ±100c、サブオクターブ、上オクターブ |
| 音色 | 倍音数 1–48、倍音の減衰（1/n^x）、奇数↔偶数、ユニゾン 1–5、デチューン、フィルター、レゾナンス |
| 有機的揺らぎ | ピッチの揺らぎ（c）、揺らぎの速さ 0.003–0.6Hz、音量の揺らぎ、ステレオ幅 |
| 駆動モード | 持続 / タンプーラ / 両方、1周の長さ、余韻、ジャワリ |
| 療法レイヤー | 刺激周波数 0.5–60Hz、ドローンへのAM深さ、AM波形（正弦/パルス）、アイソクロニック音、バイノーラル、キャリア周波数、キャリアを基音に追従 |
| 共鳴呼吸ガイド | 呼吸数 0–12回/分、吸う割合、音量の膨らみ、音色の開き |
| 空間 | リバーブ量・残響時間、ディレイ量・時間・フィードバック |
| セッション | 音量、フェードイン、セッション長（0=無制限）、フェードアウト |

保存形式は既存モジュール（EL-SYSTEMA 系）と同じ `exportParams()` / `applyParams()` で、`{ app, version, params }` のJSONです。

## 収録音階（53種）

- **日本・琉球**：琉球音階（12平均律／5-limit純正律）、民謡、都節、陽、平調子、雲井、岩戸
- **インド・ラーガ**（22シュルティの純正比）：ヤマン、バイラヴ、バイラヴィ、トーディ、マールワー、ブーパーリー、マールカウンス、カーフィー
- **アラブ・マカーム**（24平均律）：ラースト、バヤーティー、ヒジャーズ、サバー、スィーカー、クルド、ナハーワンド
- **トルコ・マカーム**（53コンマ）：ウッシャク、ヒジャーズ、ラスト
- **ペルシア・ダストガー**：シュール、チャハールガー、ホマーユーン
- **インドネシア・ガムラン**（実測近似）：スレンドロ、ペロッグ、スリシール
- **東アジア**：中国五声（宮・商・角・徴・羽、ピタゴラス）、韓国 平調・界面調
- **東南アジア**：タイ7平均律
- **アフリカ**：エチオピア・キニット5種、ショナ・ムビラ（近似）
- **ユーラシア・地中海**：フライギッシュ、ハンガリー短音階、ビザンチン第1旋法（近似）
- **倍音・理論**：倍音列8–16、純正長音階、パーチ11-limit、12平均律

ガムラン・ムビラ・ペルシア音楽などは楽団・奏者ごとに音律が異なり、収録値は代表的な近似です。正確な楽器の調律を使いたい場合は `.scl` を読み込んでください。

## 療法レイヤーの考え方

詳しい背景と出典は [docs/RESEARCH.md](docs/RESEARCH.md)。要点だけ書きます。

- **40Hz**：40Hz前後の音は聴覚定常状態反応（ASSR）を最も強く引き起こすことが知られ、マウスでの研究（Iaccarino 2016、Martorell 2019）からアルツハイマー病への応用が研究されています。ヒトでの効果はまだ臨床試験の段階です。本楽器では「ドローン全体を40Hzで振幅変調」「40Hzで断続するクリック的な音」「左右差40Hzのバイノーラル」を独立に混ぜられます。
- **共鳴呼吸（約6回/分＝0.1Hz）**：心拍変動（HRV）バイオフィードバックで使われる呼吸数で、自律神経系への効果のエビデンスが比較的厚い領域です。音量と音色の満ち引きを呼吸のペースメーカーにしています。
- **バイノーラルビート**：効果の研究結果は一致しておらず、メタ分析でも条件によるばらつきが大きいとされます。体験の一要素として扱ってください。
- 432Hz・Om 136.1Hzなどの基音プリセットは文化的な慣習値で、医学的根拠を主張するものではありません。

## ローカルで動かす

ES Modules を使うため、`file://` で直接開くとブラウザが読み込みを拒否します。

```bash
git clone https://github.com/<you>/kukuru-drone.git
cd kukuru-drone
python3 -m http.server 8080      # または npm run serve
# → http://localhost:8080
```

テスト（Node.js 20以上）：

```bash
npm test
```

### GitHub Pages で公開

リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にするだけで動きます（`.nojekyll` 同梱）。

## 今後の拡張候補

- 響庭（Resonant Garden）系センサー入力：コンタクトマイクや植物の生体電位を `rootHz`・`driftCents` に写像（Web Serial / OSC ブリッジ）
- 心拍センサー（BLE）で呼吸ガイドの速さを実測HRVに合わせる
- 40Hzの視覚刺激（光点滅）は光過敏発作の危険があるため、意図的に実装していません。追加する場合は明示的な同意画面と強度制限を必須にしてください。
