# HYPOGEUM // KKR-40

低域（20〜250Hz）で使う**ベース・ドローン楽器**。13の音色エンジン、世界53種の民族音階、音楽療法の知見（40Hz聴覚刺激・共鳴呼吸・バイノーラル）を、暗号めいた計器盤で操作します。ブラウザだけで動き、実行時の依存ライブラリはありません。旧名 **KUKURU**。

> *hypogeum*（ヒポゲウム）は地下の石室。低い音と、体の内側で鳴る空間の比喩です。

A low-frequency (20–250 Hz) drone instrument for the browser: 13 bass engines (Reese, 2-op FM, wavefolder, subharmonic divider, ladder, PWM, drawbar organ, kargyraa, didgeridoo, bowed bass, tape comb, sine, additive), 53 world tunings plus Scala `.scl`, a low-end master chain (subsonic HPF, mono crossover, missing-fundamental enhancer, soft clip, limiter), and the music-therapy layers of the original KUKURU — 40 Hz AM / isochronic, binaural, 0.1 Hz resonance-breathing guidance. Pure Web Audio, ES modules, no build step.

**公開版**: https://soundwaterinc-oss.github.io/hibikiniwa-instruments/apps/hypogeum/ （響庭 楽器群のリポジトリ `hibikiniwa-instruments` の一部。共通基盤 `packages/core` を使います）

## 計器盤の読み方

すべてのパラメータ・グループ・音階・プログラムは**コード名**で表示されます（例：`F₀`＝基音、`Γ.hz`＝刺激周波数、`RYK-5/J`＝琉球音階の純正律）。

- ヘッダーの **[DECODE]** を押すと、全ラベルに平文の意味が併記されます（状態はブラウザに保存）。
- どのコントロールも、マウスを載せたときの説明（`title`）とスクリーンリーダー用の名前（`aria-label`）は常に平文です。
- 全コードの対応表は [docs/CODEBOOK.md](docs/CODEBOOK.md)（`js/codebook.js` から自動生成）。
- **安全注意だけは暗号化していません**。初回表示時は開いた状態で出ます。

| グループ | 平文 | 主なパラメータ |
|---|---|---|
| `§0x1 TUN` | 調律 | `F₀` 基音 20–250Hz（対数、初期値 41.2Hz＝E1）、`Δ¢` 微調整、`SUB.k` サブオクターブ、`SUP.k` 上オクターブ |
| `§0x2 EXC` | 駆動モード | `EXC.m` 持続／タンプーラ／両方、`T.cyc` 1周、`τ.dk` 余韻、`JWR` ジャワリ |
| `§0x3 GEN` | 音色エンジン | `ENG` エンジン選択、マクロ `Α` `Β` `Γ`（意味はエンジンごと）、`H.n` `ρ` `O/E` `U.n` `δ`（ADD.H用）、`LP.ω` `LP.Q` |
| `§0x4 DRF` | 有機的揺らぎ | `ΔF.¢` ピッチの揺らぎ、`ΔF.hz` 速さ、`ΔA` 音量の揺らぎ、`W.st` ステレオ幅 |
| `§0x5 Γ40` | 療法レイヤー | `Γ.hz` 刺激周波数、`AM.d` AM深さ、`AM.w` AM波形、`ISO.k` アイソクロニック、`BIN.k` バイノーラル、`C.hz` キャリア、`C.lk` 追従 |
| `§0x6 Φ.RSP` | 共鳴呼吸 | `Φ.bpm` 呼吸数、`Φ.in` 吸う割合、`Φ.A` 音量の膨らみ、`Φ.ω` 音色の開き |
| `§0x7 SPC` | 空間・低域マスター | `RV.k` `RV.t` リバーブ、`DL.k` `DL.t` `DL.fb` ディレイ、`HPF.ω` `MONO.x` `PSY.h` `DRV` |
| `§0x8 SES` | セッション | `VOL` 音量、`F.in` フェードイン、`S.min` セッション長、`F.out` フェードアウト |

数値は等幅の計器表示で、Hz と秒は指数表記（`F₀ 4.12E+1 Hz`）、整数は16進（`0x03`）、セントは符号付きです。単位は必ず併記します。

## 音色エンジン（`§0x3 GEN` → `ENG`）

どのエンジンも持続音（ドローン）として成り立つように作ってあり、持続・タンプーラ（撥弦）・両方のどのモードでも鳴ります。タンプーラでは、選んだエンジンをエンベロープで撥弦させます。

| コード | 中身 | Α | Β | Γ |
|---|---|---|---|---|
| `ADD.H` | 加算合成（PeriodicWave の倍音列、旧KUKURUの音。既定） | 倍音数（H.n からの増減） | 減衰（ρ からの増減） | 奇偶（O/E からの増減） |
| `SIN.0` | 純正弦＋2・3倍音、tanh飽和 | 2倍音量 | 飽和 | 3倍音量 |
| `R33S` | リース：デチューンしたノコギリ2〜4本、位相がゆっくりずれる | デチューン | 本数 | LPの開き |
| `FM.2` | 2オペFM（比率 0.5/1/2/3）。正弦と鋸歯状のモジュレータを混ぜてフィードバックFM風に | 変調指数 | 比率 | 歪み |
| `F0LD` | 正弦 → ウェーブフォールダー（Buchla系） | 折り返し量 | 対称性 | 後段LP |
| `UNDR` | アンダートーン分周 f/2・f/3・f/4 の矩形（Subharmonicon的） | f/2 | f/3 | f/4 |
| `L4DR` | ラダーLP近似（biquad 4段＋各段tanh）をノコギリに | カットオフ | レゾナンス | ドライブ |
| `PWM` | パルス幅変調（ノコギリ2本の位相差法） | 幅 | 速さ | 深さ |
| `ORG.16` | ドローバー・オルガン 16′ 8′ 5⅓′ 4′（16′＝F₀） | 16′ | 5⅓′ | 4′ |
| `KRG` | カルグラ：ノコギリ＋f/2の周期倍化＋母音フォルマント | 母音 o→u→a | 分周量 | ざらつき |
| `D1DJ` | ディジュリドゥ：低いパルス列＋口腔フォルマントの掃引 | 掃引幅 | 掃引速度 | 唇の詰まり |
| `B0W` | 擦弦ベース：ノイズ励起＋フィードバック・コム（Karplus持続版） | 弓圧 | 胴鳴り | 減衰 |
| `TAPE` | 低域ノイズ＋共鳴コム＋ワウ・フラッター | 共鳴 | フラッター | 帯域 |

実装は `js/engines/*.js` に1エンジン1ファイルで、共通インターフェース `create(ctx, { hz, out, params, drift }) → { setHz(hz, t, glide), setParams(p), release(sec) }` を持ちます。各エンジンは1ボイスあたりの音源コストを申告し、同時ボイス×オシレータ数が上限（`VOICE_BUDGET`）を超える場合は、上オクターブなど優先度の低いボイスから省きます（GENパネルに `VOICES 使用数/要求数` を表示）。

フィードバック・コムを使う `B0W` と `TAPE` は、ループ内ローパスの位相遅れを遅延時間から差し引いて音程を合わせています。Web Audio の閉路は128サンプル以上の遅延が必要なので、高い音では周期の整数倍の遅延にしています。

## 低域マスター処理（`§0x7 SPC`）

```
ボイス ─▶ LP.ω ─▶ Γ40 AM ─▶ Φ呼吸 ─▶ 残響・ディレイ
   ─▶ DCカット ─▶ HPF.ω（18〜30Hz、24dB/oct＝biquad 2段）
   ─▶ MONO.x クロスオーバー（LR4）：下はL+Rをモノ化、上だけ W.st のM/S幅
   ─▶ ＋ PSY.h（低域を抽出 → 2・3倍音を生成 → 90Hz以上だけ足す）
   ─▶ ＋ 療法音（アイソクロニック／バイノーラル：モノ化・残響を通さない）
   ─▶ セッション ─▶ VOL ─▶ 共通マスター段（packages/core/master.js：DCカット → DRV ソフトクリップ → ルックアヘッド・リミッター −1 dBTP 目安 → メーター）
```

- **PSY.h** は「ミッシング・ファンダメンタル」効果を使います。2・3倍音があると、脳は鳴っていない基音を補って聴きます。基音を再生できない小型スピーカーやノートPCでも、低音の高さが感じられます。
- 基音が `Γ.hz`（刺激周波数）の±3Hz以内で AM かアイソクロニックが有効なとき、AMと干渉してうなりになるため、平文の注意を表示します。
- バイノーラルのキャリアは低域では左右差が知覚しにくいため、下限を 120Hz に固定しています（追従時は基音を120〜520Hzへオクターブ移動）。

- **東アジア** `EAS`：中国五声（ピタゴラス `/P`）、韓国 平調・界面調

## 療法レイヤーの考え方

詳しい背景と出典は [docs/RESEARCH.md](docs/RESEARCH.md)。要点だけ書きます。

- **40Hz**：40Hz前後の音は聴覚定常状態反応（ASSR）を最も強く引き起こすことが知られ、マウスでの研究（Iaccarino 2016、Martorell 2019）からアルツハイマー病への応用が研究されています。**ヒトでの効果はまだ臨床試験の段階です。** 本楽器では「ドローン全体を40Hzで振幅変調」「40Hzで断続するクリック的な音」「左右差40Hzのバイノーラル」を独立に混ぜられます。
- **共鳴呼吸（約6回/分＝0.1Hz）**：心拍変動（HRV）バイオフィードバックで使われる呼吸数で、**自律神経系への効果のエビデンスが比較的厚い**領域です。音量と音色の満ち引きを呼吸のペースメーカーにしています。
- **バイノーラルビート**：**効果の研究結果は一致しておらず**、メタ分析でも条件によるばらつきが大きいとされます。体験の一要素として扱ってください。
- 432Hz・Om などの基音プリセットは文化的な慣習値で、医学的根拠を主張するものではありません。
- 40Hzの**視覚**刺激（光の点滅）は光過敏発作の危険があるため、意図的に実装していません。位相ダイヤルも刺激周波数に同期して点滅しません。

## ローカルで動かす

リポジトリのルートで `HIBIKINIWA.bat` をダブルクリック（Windows）するか、`npm run serve` を実行し、http://localhost:8080/apps/hypogeum/ を開きます。ES Modules を使うため、`index.html` をダブルクリック（`file://`）で開いても動きません。

## テスト

リポジトリのルートで：

```bash
npm install            # devDependency（node-web-audio-api・@napi-rs/canvas）だけを入れる
npm test               # 音階・コードブック・v1→v2変換（HYPOGEUM 分は tests/hypogeum.*.test.mjs）
npm run smoke          # 全エンジン × 基音 27.5 / 41.2 / 82.4Hz を各2秒描画（scripts/smoke-hypogeum.mjs）
npm run codebook       # docs/CODEBOOK.md を再生成
```

スモークの合格条件：NaNなし、ピーク ≤ 0.95、DC成分 < 0.01、スペクトル重心 < 500Hz、40Hz AM の深さ1.0で包絡の最小値がほぼ0、全エンジンがタンプーラ（撥弦）モードで発音すること。

## GARDEN BUS

ヘッダーの BUS ボタンで OFF → MST（master）→ FLW（follow）を切り替えます。
- **FLW（STOMA//16 が master）**：STOMA のテンポに合わせ、呼吸ガイド（Φ.bpm）とドリフト（ΔF.hz）の周期を小節の整数倍にそろえ、吸い始めを小節の頭に合わせます。基音は STOMA の F₀ に追従します。
- **MST**：基音と音階（コード・セント・鳴らしている度数）を流します。STOMA は低音（T トラック・SUB 音色）をこの音階の度数に量子化します。
