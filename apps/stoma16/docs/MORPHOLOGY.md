# 形態学の背景と、解析・音楽の設計

STOMA//16 は「細胞の形の統計」をリズムに読み替える楽器です。ここでは、使っている形態学の知見と、解析・音楽の設計判断をまとめます。

## 1. 平面を埋める細胞の幾何

### 平均隣接数 ⟨n⟩ ≈ 6
平面をすき間なく分割し、各頂点で3つの細胞が出会う（三重点）とき、オイラーの多面体定理から**1細胞あたりの平均の辺数（＝隣接数）は 6 に近づく**ことが導かれます。上皮・コルク・泡など、自然の多くの組織で ⟨n⟩ は 5.9〜6.0 前後です。

ただし ⟨n⟩ ≈ 6 は「どんな切り分けでもほぼ成り立つ」性質でもあります。細胞を2つに割っても、2つをくっつけても、平面分割である限り平均は6付近に寄ります。そのため STOMA の AUTO は **⟨n⟩ だけでは採点しません**（5.3〜6.5 の外側だけを減点）。

境界（画像の縁）に触れる細胞は隣接数が欠けるので、⟨n⟩ などの統計は**縁に触れない細胞だけ**で数えます（隣の細胞としては縁の細胞も数える）。

### 六角形率
隣接数がちょうど6の細胞の割合。コルクや蜂の巣状の組織で高く、細長い煉瓦積み（タマネギ表皮）やジグソー状の表皮では低くなります。

### ルイスの法則（Lewis's law, 1928）
細胞の**面積は辺の数にほぼ比例して増える**（n 辺の細胞の平均面積 Ā(n) は n の一次関数）。STOMA では、辺の数と面積（平均で割ったもの）の相関係数 **LEWIS r** と傾きを表示します。

### アボフ–ウィアの法則（Aboav–Weaire law）
**辺の多い細胞の隣には、辺の少ない細胞が来やすい**。n 辺の細胞に隣接する細胞の平均辺数を m(n) とすると、

  n · m(n) = (6 − a) · n + 6a + μ₂

がよく成り立ちます（μ₂ は辺数の分散、a は係数で、多くの組織・泡で 1 前後）。STOMA は n · m(n) を n に対して回帰し、係数 **a** を表示します。

### 凸包率
細胞の面積 ÷ 凸包の面積。丸い・多角形の細胞は 1 に近く、葉の表皮のジグソー状の細胞（波打つ垂層壁）は小さくなります。Z トラック（ノイズ・質感）の振り分けに少し効かせています。

### 隣接細胞との面積比・向きの局所的な揃い
隣の細胞の平均面積 ÷ 自分の面積、隣との長軸の向きの揃い（|cos 2Δθ| の平均）。組織の境目や、細胞が一方向に引き伸ばされた領域で特徴的な値をとります。

## 2. 組織の見え方

### 孔辺細胞と気孔
葉の表皮で、2つの腎臓形の**孔辺細胞**が向かい合って**気孔**（ガス交換の穴）を作ります。周りの表皮細胞より小さく、形もはっきり違うので、H トラック（小さい細胞）に振り分けられやすくなります。STOMA（気孔）という名前の由来です。

### 内皮とカスパリー線
根の横断面では、外側から**表皮 → 皮層 → 内皮 → 内鞘 → 中心柱（維管束：木部・篩部）**の順に同心円状に並びます。**内皮**の細胞壁には**カスパリー線**（スベリン・リグニンが沈着した帯）があり、水と溶質が細胞壁の中を素通りするのを止めます。サフラニン染色ではこの帯が赤く染まるため、写真では中心柱を囲む**赤い環**として見えます。

STOMA の同心円の検出は、この赤い環のような**環状の組織クラス**に円をフィットして回転走査の中心を推定します。環状のクラスが見つからないときは、**細胞の大きさの放射状勾配**（中心ほど小さい・大きい）が最も強くなる点を中心とします。推定した中心からの距離で「環（リング）」を定義し、SWEEP の小節や EVO の TISSUE の区間に使います。

## 3. 切り分け（セグメンテーション）

### 特徴チャンネル
| コード | 何を壁とみなすか |
|---|---|
| LUMA | 暗い壁（INV で明るい壁）。線の検出に、太い壁のための局所コントラストを足す |
| CHL | 葉緑体・染色の**密度の谷**。細胞が葉緑体で満ちていると、その間の透明な帯が壁になる |
| WALL | 明るく色の抜けた線（透明な細胞壁） |
| RIDGE | ヘッセ行列による線の検出（INV で明るい線＋彩度ゲート） |

### リッジ検出（Frangi 型）
画像をガウスでぼかしてヘッセ行列（2階微分）を作り、その固有値 |λ₁| ≤ |λ₂| から「線らしさ」を測ります（Frangi et al., 1998）。線の上では、線を横切る方向の曲率 |λ₂| が大きく、線に沿う方向の曲率 λ₁ は小さい。塊（核・葉緑体）では両方が大きいので、比 λ₁/λ₂ で抑えます。壁の太さに合わせて複数のスケール（σ）で計算し、最大値を採ります。明るい線を探すときは、色の付いた部分（葉緑体の縁など）を彩度で弱めます（彩度ゲート）。

**線の連続性（LIN）**：線の向きに沿って応答を平均すると、まっすぐ続く壁は残り、葉緑体の縁のような短く曲がった線は弱まります。

### 二値化から境界まで
1. **ヒステリシス閾値**：強い閾値（THR.H）を超える線を種に、弱い閾値（THR.L）以上へつなげる（Canny と同じ考え方）。
2. **細線化**（Zhang–Suen）で1画素幅の骨格にし、端の小枝を刈る。
3. **端点の延長**：骨格の端点から、その向きに GAP 画素まで伸ばし、別の壁に届けばつなぐ（途切れの補修）。
4. **短い孤立線分と小さな閉じた輪を除去**：壁と交わらない小さな閉じた輪（核や葉緑体の縁取り）は「細胞の内容物」として埋め戻す。開いた線分は壁の断片として残す。
5. **マーカー付きウォーターシェッド**：壁に囲まれた内部（マーカー）から、壁らしさの低い所から順に水を満たす。境界は壁らしさの尾根＝**壁の中央**に来る。
6. **弱い境界の併合**：境界の壁らしさが中央値に比べて弱い隣同士をつなぐ（断片化の後始末）。

### evidence と AUTO
- **evidence** ＝ 境界上の壁らしさの平均 ÷ 画像全体の平均（境界は±1画素の範囲の最大値）。境界が壁の上にあるほど大きい。
- **AUTO の採点**は **excess**（Σ（境界上の壁らしさ − 画像の85%分位点））× ⟨n⟩ の妥当さ。本当の壁を境界にすると増え、壁でない所を切ると減るので、細かく切るほど得にはならず、断片化（葉緑体の塊で細胞が割れる）を選びません。平均の evidence は「弱い本物の壁を落とすほど上がる」性質があるため、採点には使いません。
- 探索は2段階（①特徴 CH・INV・σ の12通り、②上位3つで閾値を詰める）で、Worker に並列に配ります。

### 組織の分類
各細胞の平均色（CIE Lab）と形態量（面積の対数、細長さの対数、凸包率）を標準化し、色に重みを置いて k-means（k-means++ 初期化）にかけます。k は 2〜6 からシルエット係数で選び、最大値に近い（−0.06 以内）なら組織を細かく分ける方を採ります。名前は色名（Lab の色相角と彩度）＋大きさ（中央値との比）で自動で付けます（例 `TIS.R-sm` ＝ 赤・小さい）。細胞の平均色は白い内部と染まった壁が混ざって淡く紫寄りになるため、赤の色相の範囲を 310〜50 度と広めにとっています。

## 4. 4つのスタイルの手法

各作家の作品を模倣するのではなく、**手法の一部を合成音で再現するスタディ**です。サンプル（録音素材）は使いません。

### REF.TWL — Azu Tiwaline
チュニジアの電子音楽家。ダブの空間処理と、サハラの枠太鼓（ベンディール）のポリリズムを重ねる。
- 16分割と12分割（3連）のトラックが重なり、**3:4 のヘミオラ**。12分割のトラックをループごとに1ステップずつ回して、重なりを少しずつずらす。
- **スプリング残響**（分散で音程が下がるチャープの繰り返し）、深いダブディレイ、ノイズの「投げ」。
- 基音の**サブドローン**（GARDEN BUS の基音に従う）。

### REF.IKD — Ryoji Ikeda
データを音と映像の素材として扱う作曲家。
- 純正弦のバースト、ホワイトノイズのゲート、単一サンプルのインパルス。**64分割**の完全量子化、K 以外は左右に振り切る。
- 高域トーンの1小節あたりの総量に上限を設け、耳が疲れないようにする。
- 細胞のデータ（面積・隣接数・向き）を**数値行列とバーコード**で表示。更新は拍ごと（8Hz 未満）。

### REF.BDM — Budamunk
東京のビートメイカー。MPC のスウィングと、ざらついた質感。
- **MPC 表記のスウィング**（50〜75%：16分の裏を、8分の何%の位置に置くか）、**16段階のベロシティ**。
- 合成した1小節のループを16分割し、細胞の大きさで選んだ断片を鳴らす**チョップ**。
- キックで他のトラックを沈める**サイドチェイン**、ビットクラッシュ、レコードのチリ。

### REF.JLN — Jan Jelinek
クリック＆カット（クリックス・アンド・カッツ）の作家。ジャズの極小の断片をループにする。
- **グラニュラー**：粒の長さ＝**細胞の周長**。和音の断片を細かく並べる。
- **テープのワウ・フラッター**、ヒス、チリ、**64分のクリック層**。

## 5. 実写真の入手とライセンス

- **Wikimedia Commons**（https://commons.wikimedia.org/ ）で "root cross section", "moss leaf cells", "onion epidermis", "stomata" などを検索すると、顕微鏡写真が多数あります。ライセンス（CC BY / CC BY-SA / パブリックドメインなど）と作者の表示条件は**画像ごとに異なる**ので、ページの「ライセンス」欄を確認してください。
- **Cell Image Library**（https://www.cellimagelibrary.org/ ）も研究用の画像が豊富です。利用条件は画像ごとに確認してください。
- 教科書・論文・ウェブサイトの写真は著作権で保護されていることが多く、出典が分からない写真を配布物に含めてはいけません。このリポジトリのテスト用写真（`fixtures/root_xs.jpg`, `fixtures/moss_leaf.jpg`）も出典が確認できないため、**リポジトリには含めていません**。テストは写真がある環境でだけ実行され、無ければスキップされます。
- 自分で撮る場合：タマネギの鱗片葉の表皮（ヨウ素液で染めると核が見える）、オオカナダモや苔の葉（葉緑体）、ツユクサの葉の裏の表皮（気孔）は、身近で観察しやすい標本です。USB 顕微鏡なら **CAM** でそのまま解析できます。
