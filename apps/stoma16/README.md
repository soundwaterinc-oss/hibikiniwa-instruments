# STOMA//16

植物細胞の顕微鏡写真を切り分け、細胞の**面積・隣接数・細長さ・向き・組織の種類**を、ビートの位置と音色に変換するリズム楽器です。ブラウザだけで動き、実行時の依存ライブラリはありません。解析はすべて Web Worker で行います。

**公開版**: https://soundwaterinc-oss.github.io/hibikiniwa-instruments/apps/stoma16/

## 流れ

```
写真（長方形のまま） ─▶ 特徴チャンネル（LUMA / CHL / WALL / RIDGE）─▶ 壁らしさ地図（多重スケールの Frangi 型ヘッセ・フィルター）
  ─▶ ヒステリシス二値化 ─▶ 細線化 ─▶ 端点の延長で途切れを補修 ─▶ 短い孤立線分・小さな閉じた輪（核・葉緑体の縁）を除去
  ─▶ マーカー付きウォーターシェッド（境界＝壁の中央）─▶ 弱い境界の併合 ─▶ 形態量・隣接グラフ・統計
  ─▶ 組織の分類（Lab色＋形態量の k-means、k はシルエット係数で選ぶ）─▶ 同心円構造の検出
  ─▶ 声部（K T S H C Z）への振り分け ─▶ 時間写像（SWEEP / RASTER / WALK）─▶ トラックごとのループ（ポリメトリック）
  ─▶ スタイル（REF.TWL / IKD / BDM / JLN）の音色・揺れ・質感 ─▶ EVO（自動展開）
```

詳しい背景（⟨n⟩≈6、ルイスの法則、アボフ–ウィアの法則、孔辺細胞、内皮とカスパリー線、リッジ検出、組織分類、4スタイルの手法）は [docs/MORPHOLOGY.md](docs/MORPHOLOGY.md)。

## 使い方

1. 標本を選ぶ（生成標本 4種。リポジトリの `fixtures/` に写真があるローカル環境では **LOC.ROOT / LOC.MOSS** も出ます）か、写真をドロップ・貼り付け・LOAD。カメラや USB 顕微鏡は **CAM**（4秒ごとに再解析し、ループの切れ目でパターンをクロスフェード）。
2. **AUTO**：切り分け設定を Worker で並列に探索し、進捗と選んだ理由（細胞数・⟨n⟩・evidence）を表示します。細胞が4個未満なら **NO CELLS** と表示し、無音のまま放置しません。
3. スタイルを選んで **▶ RUN**。標本をクリックすると走査の中心を置けます（ダブルクリックで自動推定に戻す）。
4. **VIEW** で輪郭の色分けをトラック／組織クラスに切り替え。

| 操作 | 内容 |
|---|---|
| スペース | 再生・停止 |
| レーン図 | 打点をドラッグ＝微小タイミング（±半ステップ）、クリック＝追加・削除。キーボード：←→ ↑↓ 移動、Enter 追加/削除、[ ] 微調整 |
| VOX 表 | トラックごとに音色（16種）・音量・音程・減衰・形の引き寄せ・ループ長（POLY=MAN）・マクロ M1/M2 |
| EXP.MID / EXP.WAV / EXP.JSON | .mid（4小節）、4小節の WAV（オフライン描画）、設定 JSON |
| MIDI.LNK / LEARN | 入力：任意のコントロールに CC を割り当て、ノートで基音 F₀。出力：各トラックをノートで送る（GM ドラム、T は ch1 の音程） |
| REC | マスター出力を録音して WAV で保存 |
| BUS | GARDEN BUS：OFF → MST → FLW |
| Ctrl+Z | 元に戻す（直近20操作） |

## 主な仕組み

- **アンカー**：スタイルごとに拍の頭に必ず置くトラック（TWL／BDM はキックの1拍目、BDM はスネアの2・4拍も）。
- **ポリメトリック**：トラックごとにループ長 16／12／10／7 ステップを選べます（POLY=MAN）。AUTO は細胞の周長から導きます。
- **組織クラス**：振り分けの追加条件（TIS.k）、EVO の TISSUE で区間と音色に使います。
- **EVO**：ARC / DUB / MIN / DRF / **TISSUE**（同心円の外側の環から内側へ。環で多い組織の色で音色が変わる）。BUILD は密度とフィルターを指数的に上げ、BREAK はダブディレイの帰還を自動で上げ下げ。STYLE CYCLE は区間ごとに次のスタイルへ段階的に移ります。SEED を固定すると展開を再現できます。
- **細胞の向き（ANG）**：定位（PAN）や音色のマクロ2（TONE）に写像できます。

## 安全とプライバシー

画面全体の明滅や毎秒8回以上の点滅はしません（IKD の数値行列・バーコードも拍ごとにしか変わりません）。カメラの映像と読み込んだ写真は端末の中だけで処理し、どこにも送信しません。

## 実写真について

テストに使う2枚（根の横断面・苔の葉）は出典とライセンスが確認できないため、リポジトリには含めていません（`fixtures/` は .gitignore）。入手方法とライセンスの注意は [docs/MORPHOLOGY.md](docs/MORPHOLOGY.md#実写真の入手とライセンス)。

## ファイル構成

```
apps/stoma16/
  index.html, css/style.css
  js/codebook.js       コード名 ↔ 平文
  js/params.js         パラメータ（共通基盤のスキーマ駆動UI）・旧版からの変換
  js/specimens.js      標本の生成（canvas を使わない純粋なラスタ処理。決定的）
  js/analysis/         image（縮小・Lab）/ ridge（Frangi・線の連続性）/ segment（ヒステリシス・細線化・補修・ウォーターシェッド・併合）
                       morph（形態量・隣接・統計）/ classify（k-means・シルエット・命名）/ concentric（同心円）/ auto（AUTO の採点）
  js/worker.js, js/analysis-client.js   解析 Worker と、AUTO を並列に配る束ね役
  js/map.js            細胞 → 打点（時間写像・振り分け・アンカー・ポリメトリック）
  js/evo.js            自動展開
  js/voices.js         スタイル標準キットと16音色
  js/audio.js          バス・質感・スケジューラ（共通マスター段へ）
  js/session.js        演奏の流れとオフライン描画
  js/scope.js, js/lanes.js   標本の表示、レーン図
  js/export.js         .mid の書き出し
  js/garden.js         GARDEN BUS 連携
  docs/MORPHOLOGY.md
```
